# Data note

This repository contains only the code and documentation from the original
`scRNAseq_cell_type_classification` project directory. The large reference
data and model files (~18GB total, including pre-trained models, Tabula
Muris/Tabula Sapiens reference datasets, sample datasets, and test run
outputs) were excluded because they exceed GitHub's file size limits and
are not suitable for version control.

See the `README` files in each `reference_data` subdirectory for
information on how to obtain the corresponding reference data.
